# IPL Historic Dashboard

A comprehensive, visually premium single-page IPL dashboard covering all 18 seasons (2008–2025) with rich data cards, interactive charts, and analytical insights.

## Features

- **18 season cards** (2008–2025) detailing Champions, Orange Cap, Purple Cap, Emerging Players, and MVPs.
- **Interactive Rankings Tracker** built with HTML5 Canvas. Includes isolated highlighting and normalized team tracking across seasons.
- **All-Time Records & Trivia** showcasing historic milestones and interesting facts.
- **Correlation Analysis** examining the impact of toss, chasing trends, and playoff consistency.
- Pure HTML/CSS/JS without external libraries. Premium dark mode aesthetic.

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. (Optional) Run a local development server for the best experience: `python3 -m http.server 8080`
